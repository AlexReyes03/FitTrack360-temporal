# Aviso de privacidad

## Cuenta

FitTrack360 registra nombre, usuario, correo y consentimiento. Firebase Auth gestiona el acceso a la cuenta.

## Datos que registras

El servicio puede almacenar sesiones, series, rutinas, comidas, medidas corporales y fotografías proporcionadas por la persona usuaria. Las fotos se reencodan para retirar EXIF y se almacenan junto con sus metadatos técnicos.

## Uso de los datos

Los datos se usan para administrar la cuenta y mostrar los registros personales.

## Acceso y eliminación

La API permite exportar los registros personales y solicitar la eliminación de la cuenta, los archivos locales y la identidad de Firebase. Las opciones disponibles en la aplicación dependen de la versión instalada.

## Salud y nutrición

FitTrack360 es una herramienta de registro. No ofrece diagnósticos ni sustituye la atención médica o nutricional.
